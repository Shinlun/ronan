# ronan

My personal portfolio — built to showcase who I am, the work I've done, and a few side projects along the way.

Made by [Ronan Letellier](https://github.com/shinlun), fullstack tech lead.

## Stack

- **React 19** + **TypeScript** on **Vite**
- **Tailwind CSS v4** with shadcn components
- **Motion** for animations
- **react-i18next** for internationalization (🇬🇧 English, 🇫🇷 French, 🇰🇷 Korean)
- **react-router** for navigation

## Getting started

```bash
npm install
npm run dev
```

## Scripts

| Command           | Description                          |
| ----------------- | ------------------------------------ |
| `npm run dev`     | Start the dev server with HMR        |
| `npm run build`   | Type-check and build for production  |
| `npm run preview` | Preview the production build locally |
| `npm run lint`    | Lint the codebase with ESLint        |
